StockFlow

React + FastAPI + SQLite + OOP

1 What is this Project?

StockFlow is a complete stock management system where a shop or warehouse can manage their products, inventory, suppliers, and sales transactions. It has 3 user roles (Admin, Manager, Staff) with different permissions. The backend is built using Python OOP concepts demonstrating all 4 pillars of OOP — Encapsulation, Inheritance, Polymorphism, and Abstraction.

4 4 OOP Pillars — Where & How

🔒 Encapsulation

Where: Inventory._quantity, BaseProduct._cost_price

Private variables with getter/setter — quantity can only change through add_stock() and remove_stock() methods, not directly.

🧬 Inheritance

Where: PhysicalProduct & DigitalProduct extend BaseProduct

Child classes inherit common fields (name, sku, price) from parent and add their own (weight, license_type).

🎭 Polymorphism

Where: SalesReport, StockReport, SupplierReport

All have same generate() method, but each produces different output — same function name, different behavior.

📐 Abstraction

Where: BaseReport, BaseEntity, BaseContact

Abstract classes define rules (must have validate(), to_dict()) but cannot be used directly — only child classes can.
